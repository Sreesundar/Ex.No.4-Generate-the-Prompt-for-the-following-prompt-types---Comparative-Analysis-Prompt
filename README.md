Ex.No.4-Generate the Prompt for the following prompt types - Comparative Analysis Prompt Experiential Perspective Prompt - Everyday Functioning Prompts.

Aim: 
To write the prompt for the following prompt types. 
1. Comparative Analysis Prompt 

2. Experiential Perspective Prompt
   
3. Everyday Functioning Prompts 

Explanation -  Write the prompt for any one use case from Unit 5 or any 2 own use cases for each type.


PROCEDURE:

Step 1: Define the Scenario and Use Case

Scenario:
You are planning to purchase a new smartphone for daily use. The smartphone should have long battery life, AI-powered camera features, and smooth performance for daily activities such as social media usage, online classes, communication, gaming, and entertainment. You are confused between two smartphone models and need assistance in selecting the best option while understanding how the smartphone helps in everyday life.

Step 2: Identify Prompt Patterns

Select prompt patterns suitable for the scenario:

Comparative Analysis Prompt
Experiential Perspective Prompt
Everyday Functioning Prompt

Step 3: Create Comparative Analysis Prompts

Use Case 1: Smartphone Comparison

"Compare and contrast Samsung Galaxy S24 and iPhone 15 in terms of battery life, AI camera features, performance, and price."

Use Case 2: Technology Comparison

"Compare and contrast 5G and 4G network technology in terms of speed, latency, and applications."

Step 4: Create Experiential Perspective Prompts

Use Case 1: Smartphone User Perspective

"As a regular smartphone user, describe how AI-powered camera features and long battery life improve your daily activities."

Use Case 2: Student Perspective

"From a student's perspective, explain how smartphones help in online learning and productivity."

Step 5: Create Everyday Functioning Prompts

Use Case 1: Smartphone Applications

"Describe how AI features in smartphones improve photography, communication, and entertainment in daily life."

Use Case 2: Daily Technology Usage

"Explain how recommendation systems are used in daily applications such as YouTube and Netflix."

Step 6: Analyze Generated Prompts

6.1 Observe differences between prompt structures.
6.2 Analyze how each prompt type guides AI responses.
6.3 Compare the purpose and practical usage of each prompt type.
